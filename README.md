# Airesto — Страница бронирований

Страница просмотра бронирований для ресторана, разработанная на Vue 3 + Vite.

## Демо

**[https://airesto-reservations.vercel.app/](https://airesto-reservations.vercel.app/)**

## Функционал

### Основной
- Получение данных из API (с fallback на моковые данные)
- Переключение дат для просмотра бронирований
- Включение/отключение зон (1 этаж, 2 этаж, Банкетный зал)
- Фиксированные заголовки: столы — сверху, время — слева при прокрутке
- Текущее время ресторана по таймзоне, не локальное
- Все типы событий: New, Bill, Closed, Banquet, Живая очередь, Новая, Заявка, Открыт, Закрыт
- Hover-эффекты с детальной информацией
- Индикатор текущего времени на сетке

### Бонусные задания
- Тёмная/светлая тема
- Скрытие контента
- Режим выбора времени и столов для бронирования
- Кнопка «Создать» выводит в консоль: ID столов, время начала, время окончания

## Стек

- Vue 3 (Composition API + script setup)
- Vite
